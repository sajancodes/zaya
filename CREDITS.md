# Zaya — creator and credits

**Created and developed by Sajan Rai.**

Sajan Rai maintains Zaya under [sajancodes](https://github.com/sajancodes), with
source at [sajancodes/zaya](https://github.com/sajancodes/zaya). Zaya's identity,
taskbar companion, voice and expression integration, operator workflows, audio
priority, WhatsApp integration work, browser recovery, and current documentation
are developed as part of this project.

## Foundation

Zaya builds on Mark LV by **FatihMakes**. Its original copyright notice and
Creative Commons Attribution-NonCommercial 4.0 license are preserved in
[LICENSE](LICENSE).

## Dependencies

Google Gemini provides model and voice services. PyQt6/Qt provides the desktop
and media interface. Playwright provides browser automation, Hermes provides
the WhatsApp linked-device transport, and the packages in `requirements.txt`
provide additional capabilities. These dependencies retain their own authorship
and licensing terms.
